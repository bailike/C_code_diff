# C_code_diff v1.0

离线的 C/C++ 代码比对工具。**以左侧文件为基准，右侧为对比目标**，逐行显示差异。单 HTML 文件实现，无需安装，双击浏览器即可使用。

---

## 快速开始

1. 下载 `code_diff_tool_v1.0.html`
2. 双击在浏览器中打开
3. 点击 **"导入左文件"** 和 **"导入右文件"** 加载两个 .cpp 文件
4. 点击 **"整体对比"** 查看差异

---

## 主要功能

### 文件操作
- 按钮导入或拖拽文件到面板
- 自动检测编码（UTF-8 / GBK），支持手动选择
- 一键交换左右文件
- **重置**按钮恢复所有设置为默认值

### 对比模式
| 模式 | 操作 | 说明 |
|------|------|------|
| 整体对比 | 点击按钮 | 自动开启同步滚动，执行全文件 diff |
| 区域对比 | 两步流程 | （1）点击"选择区域"→ （2）点击行号选起始行 → Shift+点击行号选结束行 → （3）点击"执行对比" |
| 统一视图 | 工具栏最右侧按钮 | 单栏 +/- 前缀视图 |

### 差异显示
- **绿色** — 右侧新增行
- **红色** — 左侧删除行
- **黄色** — 修改行，行内字符级差异（左侧红色删除线 + 右侧绿色高亮）
- **蓝色** — 当前选中差异
- F7 / Shift+F7 跳转差异

### 折叠
- 连续 ≥10 行相同或不同的代码自动折叠
- 保留首行和末行可见，中间显示折叠标记
- 点击标记展开/折叠，保留滚动位置

### 搜索
- 左右面板独立搜索栏
- Ctrl+F 聚焦，F3 跳转结果
- 默认不区分大小写

### 其他
- 同步滚动（整体对比时自动开启，可手动开关）
- Ctrl+G 跳转到指定行（居中显示，若在折叠区自动展开）
- 鼠标拖选代码文本可复制
- 面板宽度可拖拽调整
- 区域对比面板高度可拖拽调整

## 算法逻辑

### 总览

以**左侧文件为基准**，5阶段处理：

```
阶段1：精确内容匹配（哈希 + 位置比例窗口）
阶段1.5：近邻位置配对（±30行紧窗口）
阶段2：左序生成差异条目
阶段3：右侧剩余行追加
阶段4：相邻 removed+added 合并为 modified
阶段5：modified 行字符级单词差异
```

### 阶段1 — 精确内容匹配

右侧文件建哈希索引 `Map<hash, [行号列表]>`。遍历左侧每行，计算期望右侧位置：

```
expectedB = round(i × lenB / lenA)
```

在 `expectedB ± maxWindow` 窗口内（`maxWindow = max(600, 15% × max(lenA, lenB))`），寻找内容完全相同的候选行，选距离最近且未被占用的行。无单调约束，允许窗口内小幅回退匹配。

### 阶段1.5 — 近邻位置配对

对阶段1未匹配的左侧行，在 `expectedB ± 30行` 紧窗口内取第一个未占用的右侧行，强制配对为 `modified`。**这是解决"函数名不同但位置对应"的关键**——如左侧 `STSSetMultiSiteBindEx` 与右侧 `STSSetMultiSiteBind` 在相同代码位置，应对齐为黄色修改行而非分离的红/绿色。

### 阶段2~3 — 按左序生成条目

严格按左侧行顺序遍历：
- 匹配行 → `same`（同内容）或 `modified`（异内容）
- 未匹配左侧行 → `removed`（红色）
- 未匹配右侧行 → `added`（绿色），插入在对应位置

### 阶段4~5 — 后处理

- 相邻 `(removed, added)` 合并为 `modified`
- modified 行做单词拆分 → 单词 LCS → 标记删除/新增单词
- 左侧显示删除单词（红色背景+删除线），右侧显示新增单词（绿色背景）

### 差异类型

| 类型 | 含义 | 左侧 | 右侧 | 颜色 |
|------|------|------|------|------|
| `same` | 相同 | 代码+行号 | 代码+行号 | 白色 |
| `added` | 仅右侧有 | 空行 | 代码+行号 | 浅绿 |
| `removed` | 仅左侧有 | 代码+行号 | 空行 | 浅红 |
| `modified` | 两侧不同 | 代码（红色删除线） | 代码（绿色高亮） | 浅黄 |
